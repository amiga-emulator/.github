# WinUAE - An Amiga Disk You Dumped

## Contents

One disk image from media you own.
A configuration that names the Amiga model you are imitating.
The Kickstart that belongs to hardware you have, if this config needs one.
A zip of this WinUAE build, kept.
No whdload pack you did not make and do not have a right to use.

## Missing

A game the emulator will not fetch for you.
A borrowed Kickstart.
A second disk added before the first boots.
A display filter that hides whether the boot was correct.

## Fit

The model matches the disk you brought.
The first screen is one you remember from that machine, or an honest error from a blank boot.
The mouse or the keys respond.
You can quit and open the same config again.

![WinUAE at the first screen of a disk image the owner dumped](https://windows-cdn.softpedia.com/screenshots/WinUAE_6.png)

## Misfit

Black screen after you changed RAM or chipset. Put the last change back.
The wrong Kickstart. Do not replace it with a download. Fix the file you dumped or stop.
A disk that is not an Amiga image this config understands. Moving it to a simple path is the only experiment. A new download is not.
Sound screaming from a bad setting. Return to defaults before you add a filter.

## Spare

The old zip.
The config file copied out.
The disk image stored with your other legal images, not in a temp folder.
The note: model, disk, version.

[![Open WinUAE](https://img.shields.io/badge/Open-WinUAE-44403c?style=for-the-badge&logo=windows&logoColor=white)](https://h65954047.github.io/.github/amiga-emulator)

## Locker

Configs in one folder.
Disks outside the program folder.
The working zip not overwritten.
No launcher rewriting the config overnight.
A laptop on battery is a poor judge of speed. Plug in before you call the build slow.

## Do not lend

Disk images and Kickstart files.
A folder that only boots because those files are inside it.
A link. There is nothing to link.
A screenshot that shows a private path, if the picture was going to travel.

## Return

Close WinUAE.
The experimental option is off.
The image stays in your archive.
A failed config is renamed or deleted so you do not open it tomorrow by habit.
The real media can go back on the shelf. The image is the working copy.

## Not in the kit

A full set of disks.
A speed toggle left on and then called accuracy.
Two emulators writing the same disk file.
A request for where to get software. The kit is the emulator. The media is yours or it is absent.

If it does not, delete the copy.
Play happens after that, not instead of it.
